## Project Overview

Galaxy Stats is a documentation site for "Once Upon a Galaxy Tournament Stats" built with:
- **Astro**: Static site generator
- **Starlight**: Astro documentation theme (provides the docs layout, sidebar, search, etc.)
- **Vue**: For interactive components via `@astrojs/vue` integration
- **TypeScript**: Strict mode enabled

## Development Commands

```bash
# Start development server
npm run dev
# or
npm start

# Build for production
npm run build

# Preview production build
npm run preview

# Run Astro CLI directly
npm run astro [command]
```

## Architecture

### Content Structure

Content is managed through Astro's content collections system, configured in `src/content.config.ts`. The `docs` collection uses Starlight's loader and schema.

- **`src/content/docs/`**: All documentation pages (`.md` and `.mdx` files)
  - Frontmatter in each file defines title, description, and other metadata
  - `index.mdx` is the landing page
  - Supports MDX for JSX-like components in Markdown

### Site Configuration

`astro.config.mjs` contains:
- Starlight configuration (sidebar, title, social links)
- Vue integration
- The `sidebar` array defines navigation structure with two approaches:
  1. Manual items with `{ label, slug }`
  2. Autogenerated sections with `{ label, autogenerate: { directory } }`

### Assets

- **`src/assets/`**: Source images and assets (referenced in content)
- **`public/`**: Static files served at root (favicon.svg)
- Sharp is used for image optimization

### TypeScript

Uses Astro's strict TypeScript configuration (`astro/tsconfigs/strict`).

## Adding Content

1. Create new `.md` or `.mdx` files in `src/content/docs/`
2. Add frontmatter with at least `title` and `description`
3. Update the sidebar in `astro.config.mjs` to include the new page
4. Reference assets relative to the content file (e.g., `../../assets/image.webp`)
