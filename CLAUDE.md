## Project Overview

Galaxy Stats is a documentation site for "Once Upon a Galaxy Tournament Stats" built with:
- **Astro**: Static site generator
- **Starlight**: Astro documentation theme (provides the docs layout, sidebar, search, etc.)
- **Vue**: For interactive components via `@astrojs/vue` integration
- **TypeScript**: Strict mode enabled

## Development Commands

### Astro / Node.js

```bash
# Start development server
npm run dev
# or
npm start

# Build for production
npm run build

# Preview production build
npm run preview

# Run Astro CLI directly
npm run astro [command]

# Parse event HTML to JSON data
npm run parse-event:py <html-file> <event-id>
# Example: npm run parse-event:py context/2026-02.html 2026-02
# Or via Make: make parse-event HTML_FILE=context/2026-02.html EVENT_ID=2026-02
```

### Python Tooling (via Makefile)

```bash
# Install Python dependencies and pre-commit hooks
make install

# Run linter and formatter
make lint

# Remove virtual environment
make clean

# Show all available commands
make help
```

### Adding Python Dependencies

```bash
# Add a runtime dependency
uv add <package>

# Add a development dependency
uv add <package> --dev
```

## Architecture

### Content Structure

Content is managed through Astro's content collections system, configured in `src/content.config.ts`. The `docs` collection uses Starlight's loader and schema.

- **`src/content/docs/`**: All documentation pages (`.md` and `.mdx` files)
  - Frontmatter in each file defines title, description, and other metadata
  - `index.mdx` is the landing page
  - Supports MDX for JSX-like components in Markdown

### Site Configuration

`astro.config.mjs` contains:
- Starlight configuration (sidebar, title, social links)
- Vue integration
- The `sidebar` array defines navigation structure with two approaches:
  1. Manual items with `{ label, slug }`
  2. Autogenerated sections with `{ label, autogenerate: { directory } }`

### Assets

- **`src/assets/`**: Source images and assets (referenced in content)
- **`public/`**: Static files served at root (favicon.svg)
- Sharp is used for image optimization

### TypeScript

Uses Astro's strict TypeScript configuration (`astro/tsconfigs/strict`).

### Data Pipeline

Event data is parsed from HTML into JSON format using `scripts/parse_event.py`:

- **Input**: Event HTML files from galaxy.fun (stored in `context/` directory)
- **Outputs**:
  - `src/data/events/<event-id>.json`: Per-player records with captain and decklist
  - `src/data/cards.json`: Deck card slug-to-display-name lookup (merged across all events)
  - `src/data/captains.json`: Captain card slug-to-display-name lookup (merged across all events)

**Parser usage**: `npm run parse-event:py context/2026-03.html 2026-03` or `make parse-event HTML_FILE=context/2026-03.html EVENT_ID=2026-03`

The parser extracts:
- Event metadata (name, date, total champion count)
- Player records (username, captain card slug, deck card slugs)
- Card display names for all referenced cards
- Separates captain cards and deck cards into distinct files for better organization

## Adding Content

1. Create new `.md` or `.mdx` files in `src/content/docs/`
2. Add frontmatter with at least `title` and `description`
3. Update the sidebar in `astro.config.mjs` to include the new page
4. Reference assets relative to the content file (e.g., `../../assets/image.webp`)
